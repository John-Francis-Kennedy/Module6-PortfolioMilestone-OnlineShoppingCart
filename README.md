# 🛒 Online Shopping Cart (Python)

## 📌 Project Overview
This project implements a **Shopping Cart system in Python** with menu-driven interaction.  
The program allows customers to add, remove, and modify items in their cart, print item descriptions, and output the cart summary with the total cost.

It is designed as part of a programming assignment to demonstrate:
- Class creation with attributes and methods
- List manipulation (add, remove, update items)
- Input-driven menus and branching logic
- Clean, modular Python code practices

---

## ✨ Features
- Add items to the shopping cart  
- Remove items from the shopping cart  
- Modify existing items (price, description, quantity)  
- Print the total number of items and overall cost  
- Print detailed item descriptions  
- Menu-driven interface (`a`, `r`, `c`, `i`, `o`, `q`)

## 🖥️ How to Run
1. Clone the repository:
   ```bash
   git clone https://github.com/John-Francis-Kennedy/Module6-PortfolioMilestone-OnlineShoppingCart.git
   cd online-shopping-cart
   ```

2. Run the program:
   ```bash
   python shopping_cart.py
   ```

3. Follow the menu options:
   ```
   MENU
   a - Add item to cart
   r - Remove item from cart
   c - Change item quantity
   i - Output items' descriptions
   o - Output shopping cart
   q - Quit
   ```
